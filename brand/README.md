# brand/ — KV 元素提取

从一张 AI 生成的品牌 KV 里，把**能用的元素**拆成可用资产。所有数值都是像素实测，不是目测。

原图：`_src/key-visual.jpg` · 1254 × 1254 · JPEG（无透明通道）

## 结论一句话

**这张稿不能直接裁进网页，但能拆出 5 类东西。** 它是美术方向，不是设计源文件。

三条硬证据说明它是 AI 渲染而非设计稿：
1. 中轴落在 x=624，画布中线 627 —— 差 3px
2. "WangZiyi" 不是真字体：W 的中竖不到顶、a 的字碗、y 的尾巴，三处收笔逻辑互不相同
3. 引导圆是「粗弧段 + 不规则缺口」随机拼接；中轴黄段长 20 / 89 / 41 / 35，无模数关系

## 实测色板

| 用途 | 色值 | 占比 | 说明 |
|---|---|---|---|
| 纸底 | `#dbdbdb` | 87.08% | 三通道 Δ≤0.2，纯中性。AI 渲染有灰度蒙雾，落地用官方 `#e8e8e2` |
| 墨 | `#242528` | 11.12% | 腐蚀 6px 取内部。B−R=+2.6（偏蓝，落在 JPEG 噪声内，不必追） |
| 强调黄 | `#f7ce12` → 取整 `#f5ce15` | **1.00%** | H 49.3° S 92.9% V 96.8°，≈ Pantone 116 C |
| 构造灰 | `#828282` | 0.84% | 四角框的横线/条码/斜纹/加号 |

> **本轮最重要的发现**：项目旧 token `--accent:#fff500` 色相 60°，比实测冷了 11°——那是柠檬黄，不是这支金铬黄。已在 `design/DESIGN-STANDARDS.md` 4.1b + 2.6 修正。

### `_tools/` — 可复现的脚本

```
analyze.py     取色与分区（点位采样 / 主色簇 / 面积占比 / 灰阶倾向）
locate.py      连通域自动定位各元素包围盒
details.py     暗部直方图 / 引导圆拟合 / 中轴分段 / 接触表
probe.py       残留碎段定位 + 紧色窗重拟合引导圆
threshold.py   墨色阈值扫描（分离引导圆与字形）
tracer.py      位图→矢量：裂缝追踪 + Douglas-Peucker（纯 numpy）
extract.py     分区提取 + 连通域筛选 + 回栅格 IoU 自检 + 比对图
make_marks.py  小件描摹 + 引导圆/中轴参数化重建 + lockup 组装
measure.py     构造件几何参数测量
verify.py      追踪结果并排目视比对
```

复现：`python extract.py && python make_marks.py`
中间产物与比对图：`_src/verify/`

## 方法要点（可复用）

1. **2× LANCZOS 上采样后二值化**再追踪 —— 1× 直追会得到阶梯边，放大一倍等于拿到亚像素精度
2. **裂缝追踪 + DP 简化** → 闭合多边形，`fill-rule="evenodd"` 自动处理内孔
3. **回栅格算 IoU 自检** —— 不靠"感觉差不多了"，本轮 93.1%–97.4%（损耗为抗锯齿边）
4. **引导圆必须放到多边形层面剔除** —— 原稿的弧段是粗描边，会与字形 8-连通粘连，连通域层面砍不断。判据：面积 <520 且中位半径落 [R±34] 环带内。Z 里的 hatch 块中位半径 300，安全保留
5. **颜色进令牌，几何进 SVG** —— 提取只产出形状，颜色一律回落设计令牌

## 提不出来的（明确留空）

| 元素 | 原因 | 处理 |
|---|---|---|
| 背景斜切面 | 渲染出的柔和渐变，无边界 | 用 `clip-path` 纯色重做 |
| 纸质颗粒 | 整图 JPEG 噪声 + 生成模型质感 | 留空 |
| 传送带等插图 | 不在 KV 内；画不好不如不画 | 留空 |
| 字标的真字体 | 不存在对应字体 | 先收轮廓；要改字换 Archivo Black / Chakra Petch 700 |
